## Project Overview

Kingbus Task Manager - 개발팀 업무 관리 시스템 (Development Team Task Management System)

A Next.js 16 application for managing development team tasks, approvals, reports, and patch notes. Uses React 19, TypeScript, and shadcn/ui components with localStorage for data persistence.

## Development Commands

```bash
# Install dependencies
npm install

# Run development server (opens at http://localhost:3000)
npm run dev

# Build for production
npm run build

# Start production server
npm start

# Run linter
npm run lint
```

### Authentication & Authorization

- **Login**: Username + password authentication via localStorage (lib/storage.ts)
- **Default Users** (password: "0000" for all):
  - 이주성 (TEAM_LEADER)
  - 김형주 (CEO)
  - 최시온 (TEAM_LEADER)
  - 신태환, 김예나, 오준희 (MEMBER)
- **Roles**: `CEO`, `TEAM_LEADER`, `MEMBER`
- **Protected Routes**: All routes under `(dashboard)` require authentication
- **Route Guards**:
  - Dashboard layout (app/(dashboard)/layout.tsx:13-18) redirects to `/` if not logged in
  - Settings page restricted to CEO/TEAM_LEADER roles (components/app-sidebar.tsx:22)

### Data Layer (lib/storage.ts)

All data persists in localStorage with these keys:
- `kingbus_users` - User accounts
- `kingbus_current_user` - Active session
- `kingbus_tasks` - Task items
- `kingbus_approvals` - Approval requests
- `kingbus_reports` - Weekly/monthly reports
- `kingbus_patch_notes` - Patch notes
- `kingbus_announcements` - Urgent announcements
- `kingbus_services` - Service types (TRP, RPA-D, Kingbus, Link variants, etc.)

**Important**: All storage functions check `typeof window === 'undefined'` for SSR compatibility.

### Key Features

1. **Task Management**
   - Categories: 일반, 기획, 디자인, 개발, 배포
   - Statuses: BACKLOG → TODO → DOING → DONE
   - File attachments (기안서, 품의서, 기타)
   - Assignees and CC recipients
   - Related tasks linking
   - Comments system

2. **Approval Workflow**
   - Two-stage approval: Team Leader → CEO
   - Links to related tasks
   - Rejection with reason
   - Next tasks planning

3. **Reports**
   - Types: Weekly, Monthly
   - Links to tasks
   - Generated by users

4. **Patch Notes & Announcements**
   - Platforms: Android, iOS, Web
   - Version tracking
   - Deadline management
   - Image attachments

## Important Notes

- **No Server-Side Data**: All data operations are client-side localStorage only
- **No Backend**: This is a pure frontend application
- **Korean Language**: UI text is in Korean (ko locale set in app/layout.tsx:38)
- **Role-Based UI**: Use `getCurrentUser()` to check permissions before showing features
- **SSR Safety**: Always check `typeof window === 'undefined'` when accessing localStorage
- **Component Imports**: Use `@/` path alias (defined in tsconfig.json:26-28)
